# Exhaust Calculator 2T – Versión 2.0.1

## Descripción
Aplicación para calcular y diseñar escapes de expansión para motores de dos tiempos (2T).

## Requisitos
- Tener Java instalado en el equipo.
- Se recomienda utilizar Java 25 o una versión compatible.

## Cómo ejecutar

**Linux:**
1. Abrir una terminal en la carpeta donde se encuentra el archivo JAR.
2. Ejecutar:

```bash
java -jar "Exaust calculator V2.0.1.jar"
```

**Windows:**
1. Tener Java instalado.
2. Hacer doble clic sobre el archivo JAR.
3. Si no se abre, ejecutar desde CMD:

```bash
java -jar "Exaust calculator V2.0.1.jar"
```
